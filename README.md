## 🚀 About novaOS

**novaOS** is an experimental/custom operating system designed with a focus on simplicity, speed, and modern architectural principles. Whether you're interested in low-level programming, kernel development, or OS design, novaOS aims to provide a clean and understandable codebase to explore how things work under the hood.

---

## ✨ Key Features

- **Lightweight Kernel:** Built with minimal overhead for maximum efficiency.
- **Modern Architecture:** Clean separation of concerns between core components.
- **Extensible Design:** Easy to write drivers, modules, and user-space applications.
- **Educational & Open Source:** Designed to be approachable for students, developers, and OS enthusiasts.

## 🛠️ Getting Started

Follow these instructions to set up and run novaOS locally in your development environment.

### Prerequisites

Make sure you have the following tools installed:
- GCC / Clang
- NASM (Netwide Assembler)
- QEMU (for virtualization/emulation)
- Make / CMake
